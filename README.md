# Amazon-webscrapper
# Overview
This project extracts data from Amazon Website using Python, BeautifulSoup, Requests instead of manual copying which is a messy process.

# Introduction 
Web scraping is an automated method used to extract large amounts of data from websites, converting HTML content into structured data like spreadsheets or databases.

# Tech Stack
Python
BeautifulSoup
Requests

# Installations
# Virtual environement creation
python -m venv myenv

# libraries installation
pip install beautifulsoup4
pip install requests
pip install lxml
